# 🎬 Netflix Content Analysis & Dashboard

> An end-to-end Data Analysis & Business Intelligence project exploring Netflix's global content catalog using Python and Power BI.

---

## 📊 Project Overview

This project analyzes Netflix's global catalog of Movies and TV Shows to uncover meaningful patterns, trends, and strategic content decisions. 

It combines Python-based data wrangling and exploratory data analysis (EDA) with an interactive Power BI dashboard styled using a custom, Netflix-inspired dark palette.

---

## 🎯 Main Objectives

* 🎬 **Content Split:** Analyze the distribution between Movies and TV Shows.
* 🌍 **Geographic Reach:** Identify top content-producing countries.
* 🎭 **Genre Breakdown:** Explore dominant genres and production categories.
* 🔞 **Target Demographics:** Evaluate content rating distributions.
* 📅 **Catalog Evolution:** Track content additions and growth over the years.
* 📈 **Growth Trends:** Uncover release timelines versus catalog ingestion trends.
* 💡 **Storytelling:** Provide executive-ready visual business intelligence.
